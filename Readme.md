# 🎮 Trivia Quiz Game

Welcome to the **Trivia Quiz Game** — a fun command-line game where you test your knowledge using real-time questions fetched from the **Open Trivia API**!

---

## 📌 Features

- Fetches **10 trivia questions** live from the internet
- Randomized multiple-choice options
- Tracks your **score** and shows results at the end
- Covers **General Knowledge** category with **Medium** difficulty

---

## 🚀 How to Run

1. **Clone this repo** or copy the code:
    ```bash
    git clone https://github.com/your-username/quiz-quest.git
    cd quiz-quest
    ```

2. **Install requirements** (only if you don’t have `requests` installed):
    ```bash
    pip install requests
    ```

3. **Run the game**:
    ```bash
    python main.py
    ```

---

## 🧠 About the API

This game uses the free [Open Trivia Database API](https://opentdb.com/api_config.php) to get trivia questions. No API key is required.
